# Murikah Tutor brand baseline

## Name

**Murikah Tutor**

## Tagline

**AI-powered personalised learning**

## Product positioning

Murikah Tutor is Murikah's personalised AI learning environment. It should feel like a native Murikah product while preserving the capabilities and maintainability of the upstream DeepTutor platform.

## Initial branding principles

- Present **Murikah Tutor** as the primary user-facing product name.
- Use **AI-powered personalised learning** as the primary product descriptor/tagline.
- Reuse Murikah brand assets only inside the Tutor application; do not modify the existing Murikah website assets as part of Tutor work.
- Keep required Apache-2.0 licence and upstream attribution intact in the appropriate legal/about locations.
- Prefer targeted branding changes over broad rewrites of upstream DeepTutor code so that future upstream updates remain practical.
- Do not couple Tutor authentication, navigation, styling, storage or runtime to the existing Murikah applications unless that integration is separately designed and approved.

## Public identity target

```text
MURIKAH TUTOR
AI-powered personalised learning

tutor.murikah.com
```
