# Murikah Tutor brand baseline

## Name

**Murikah Tutor**

## Tagline

**AI-powered personalised learning**

## Product positioning

Murikah Tutor is Murikah's personalised AI learning environment. It should feel like a native Murikah product while preserving the capabilities and maintainability of the upstream DeepTutor platform.

## Visual identity

The Tutor interface should remain quiet, academic and functional rather than becoming a heavily branded marketing surface.

Primary product tokens:

- premium slate: `#1E2A30`;
- aged brass accent: `#A9822E`;
- white/pearl text on slate surfaces; and
- the existing transparent Murikah wordmark from `docs/images/murikah_6.png`.

Because the Murikah wordmark is white, do not place it directly on the light DeepTutor sidebar. Render it on a compact slate identity surface with a restrained brass divider/accent. Keep navigation, content canvases and learning controls otherwise close to upstream so readability and future upgrades are not compromised.

## Teaching baseline

Murikah Tutor is intended to serve learners from introductory through university level across disciplines.

For ordinary learning requests, its default teaching posture is:

- rigorous enough for university-level work unless the learner requests another level;
- layered from intuition to formal reasoning, then examples or applications;
- explicit about specialised terminology, notation, assumptions and meaningful intermediate steps;
- adaptive to the learner's apparent field and level; and
- willing to use a brief check for understanding when that genuinely improves learning.

The baseline must not turn every answer into a lesson plan. Direct questions should still receive direct answers. Socratic dialogue, quizzes, extended derivations and long explanations should be used when useful or requested, not forced mechanically. Explicit learner instructions about level, style, brevity or teaching method take precedence over this default posture.

## Initial branding principles

- Present **Murikah Tutor** as the primary user-facing product name.
- Use **AI-powered personalised learning** as the primary product descriptor/tagline.
- Reuse Murikah brand assets only inside the Tutor application; do not modify the existing Murikah website assets as part of Tutor work.
- Keep required Apache-2.0 licence and upstream attribution intact in the appropriate legal/about locations.
- Prefer targeted overlay changes over broad rewrites of upstream DeepTutor code so that future upstream updates remain practical.
- Do not rename DeepTutor internal packages, environment variables, API routes, storage structures or service identifiers merely for branding.
- Do not couple Tutor authentication, navigation, styling, storage or runtime to the existing Murikah applications unless that integration is separately designed and approved.
